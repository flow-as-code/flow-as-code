# A01 FlowDoc format and typed builder

Deliverables: FlowDoc types, serializer (deterministic ordering), dagre auto-layout; builder classes for the initial block set (PlayPrompt, GetParticipantInput, CheckHoursOfOperation, TransferToQueue/Flow, InvokeLambda, InvokeModule with alias, Set* family, StartRecording, Disconnect); GenericBlock passthrough; Refs API; compile-time enforcement of wired error branches; demo flow (neutral appointment line) in tests.
Acceptance: synth of the demo flow yields a FlowDoc matching the committed conformance/demo/appointment-line.flowdoc.json byte-for-byte; an unwired error branch is a type error; a hand-crafted FlowDoc with an unknown Action round-trips synth->codegen->synth unchanged.

## Status (2026-09-01)

Landed in `packages/core/src/{flowdoc,serialize,layout,refs,blocks,flow,synth}.ts`. Block classes are named after the Connect action they emit rather than the console names listed above: `MessageParticipant` (play prompt), `DisconnectParticipant`, `CheckHoursOfOperation`, `Compare`, `TransferToFlow`, `EndFlowExecution`, `UpdateContactTargetQueue` plus `TransferContactToQueue` (transfer to queue is two actions), `UpdateContactAttributes`, `UpdateContactRecordingBehavior` (start recording), `InvokeFlowModule` with alias, `EndFlowModuleExecution`, `InvokeLambdaFunction`, and `GenericBlock`. `GetParticipantInput` landed later the same day as a DTMF menu block (`conformance/roundtrip/dtmf-menu`); its stored-input, Lex, validation and encryption forms round-trip as `GenericBlock` (packages/core/SPEC.md). `synth.test.ts` compares the demo against `conformance/demo/appointment-line.flowdoc.json` byte for byte and carries the `@ts-expect-error` cases for unwired error branches and mistyped references; `Flow.add` refuses the 251st block.
